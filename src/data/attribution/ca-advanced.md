# Attribution — Canadian Advanced bank

Canadian Advanced question bank (549 questions, EN + FR), Crown copyright, reproduced VERBATIM with attribution per the ISED license and never altered — https://apc-cap.ic.gc.ca/datafiles/amat_adv_quest.zip (fetched 2026-11-05, see data/raw/SOURCES.md).
Source: Innovation, Science and Economic Development Canada (ISED), amateur radio question banks — https://ised-isde.canada.ca/ / https://apc-cap.ic.gc.ca/datafiles/.
Shipped in the app (registry id `ca-advanced`, 50-question practice exam, 70% to pass). A future ISED bank re-write (expected in 2026) is a pipeline re-run, not a code change.
Planned explanations are a separate annotation layer delivered in each question's `explanation` field, keyed by question id — they never edit the bank text. None are written yet: every question ships with `explanationStatus: none`.

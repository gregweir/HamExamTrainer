Canadian Basic question bank (984 questions, EN + FR), Crown copyright, reproduced VERBATIM with attribution per the ISED license and never altered — https://apc-cap.ic.gc.ca/datafiles/amat_basic_quest.zip (rebased 2025-07-15; fetched 2026-11-05, see data/raw/SOURCES.md).

Planned explanations are a separate annotation layer delivered in each question's `explanation` field, keyed by question id — they never edit the bank text. None are written yet: every question ships with `explanationStatus: none`.
